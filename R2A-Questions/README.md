# R2A Algorithm Coding Question Bank

This bank contains 20 difficult algorithm-coding questions for the R2A filter. Each is an original assessment variant inspired by a linked source problem; the wording, examples, and framing here are not copied from the source. Before use, add language-specific signatures, hidden tests, and exact numeric limits to the assessment platform.

## Administration

- Give one 60–90 minute question, or two deliberately shorter questions with the same total burden.
- Randomize across categories and rotate forms. Do not let candidates select a known title.
- Permit only the languages supported by the execution environment.
- Score the submitted program with visible and hidden tests, then review the explanation for borderline candidates.
- Require the candidate to state complexity and test at least three edge cases.
- Revalidate difficulty and solve time with strong employees before operational use.
