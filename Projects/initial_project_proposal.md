## Project

To give the new hire a meaningful, high-impact project that aligns with our current needs, we propose assigning them to build an automated data ingestion and enrichment capability for our internal outreach platform.

The new module would automatically collect, validate, enrich, and update healthcare facility and decision-maker records. Today, much of this work is manual; the pipeline would connect approved data sources and vendor APIs to the existing FastAPI and Azure SQL backend, standardize incoming records, remove duplicates, verify contact information, and flag low-confidence data for human review.

The project would be well suited to a globally recruited data/backend engineer with experience in Python, data pipelines, API integrations, and cloud infrastructure. Initial delivery would focus on healthcare facility data, followed by contact enrichment and scheduled updates. This would reduce manual effort, expand outreach coverage, improve data quality, and give the email and calling agents a reliable supply of current, compliant records.
